# Working on course content

Read [COURSE_FORMAT.md](COURSE_FORMAT.md) before an authorized content edit.

- Course files in this directory are editorial source material. Architecture or styling work does not authorize editing, translating, formatting or deduplicating them.
- Keep one complete course per title-slugged YAML file, `niveau` as metadata, stable chapter identifiers, supplied references and existing public links.
- Preserve French data keys and audience text. Do not invent material or references. Use APA 7 with separate reading notes when authoring is explicitly requested.
- Keep unpublished notes private. Embedded/public exports must not include speaker notes.
